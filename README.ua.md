## Покрокове виконання завдання

### Крок 1

Створіть гілку **hw3-crud** з гілки **hw2-mongodb** та виконуйте це завдання в гілці **hw3-crud**.

Організуйте роутинг у вашому застосунку:

- винесіть код роутів з файлу  
  `src/server.js`  
  у файл  
  `src/routers/contacts.js`;

- винесіть код контролерів з файлу  
  `src/server.js`  
  у файл  
  `src/controllers/contacts.js`.

---

### Крок 2

Покращіть обробку помилок у вашому додатку.

Для цього:

1. Додайте у залежності проєкту пакет:

[http-errors](https://www.npmjs.com/package/http-errors)

2. Створіть middleware у файлі:

src/middlewares/errorHandler.js

3. Підключіть та застосуйте `errorHandler` у файлі:

src/server.js

Middleware `errorHandler` має приймати **чотири аргументи**.

У разі виявлення помилки він повинен відправляти клієнту відповідь зі статусом **500** та об’єкт такого вигляду:

```js
{
status: 500,
message: "Something went wrong",
data:
// конкретне повідомлення про помилку, отримане з об'єкта помилки
}

```

Створіть у файлі `src/middlewares/notFoundHandler.js` і застосуйте у файлі `src/server.js` middleware `notFoundHandler`, призначений для обробки запитів, коли клієнт звертається до неіснуючого маршруту.  
`notFoundHandler` у разі виявлення помилки має за допомогою [**http-errors**](https://www.npmjs.com/package/http-errors) створити помилку зі статусом **404** і повідомленням **"Route not found"**.

Створіть у файлі `src/utils/ctrlWrapper.js` і застосуйте у файлі `src/routers/contacts.js` функцію `ctrlWrapper`, яка діятиме як обгортка для контролерів у вашому Express-додатку, для автоматичної обробки помилок, що можуть виникнути під час виконання запитів. В цій обгортці при виникненні помилки викличте `next(err)` для залучення middleware `errorHandler`.

Для роута `GET /contacts/:contactId`, якщо контакт не було знайдено, то за допомогою [**http-errors**](https://www.npmjs.com/package/http-errors) створіть помилку зі статусом **404** і повідомленням **"Contact not found"**.

```js
`http-errors(404, "Contact not found")`;
```

### Крок 3

Створіть роут `POST /contacts` для створення нового контакту.

Тіло запиту має включати такі властивості:

- `name` — обов’язково
- `phoneNumber` — обов’язково
- `email` — не обовʼязково
- `isFavourite` — не обовʼязково
- `contactType` — обовʼязково

Обробка цього роута має включати:

- реєстрацію роута у файлі `src/routers/contacts.js`;
- опис контролера для цього роута у файлі `src/controllers/contacts.js`;
- створення сервісу у файлі `src/services/contacts.js`.

Відповідь сервера у разі успішного створення нового контакту має бути зі статусом **201** і містити об’єкт такого вигляду:

```js
{
  status: 201,
  message: "Successfully created a contact!",
  data:
  // дані створеного контакту
}
```

### Крок 4

Створіть роут `PATCH /contacts/:contactId` для оновлення даних існуючого контакту.

Тіло запиту може включати наступні властивості (усі необов’язкові):

- `name`
- `phoneNumber`
- `email`
- `isFavourite`
- `contactType`

Обробка цього роута має включати:

- реєстрацію роута у файлі `src/routers/contacts.js`;
- опис контролера для цього роута у файлі `src/controllers/contacts.js`;
- створення сервісу у файлі `src/services/contacts.js`.

Відповідь сервера у разі успішного оновлення даних контакту має бути зі статусом **200** і містити об’єкт такого вигляду:

```js
{
  status: 200,
  message: "Successfully patched a contact!",
  data:
  // оновлені дані контакту
}
```

Якщо контакт не було знайдено, то за допомогою http-errors створіть помилку зі статусом 404 і повідомленням "Contact not found"

```js
http - errors(404, 'Contact not found');
```

### Крок 5

Створіть роут `DELETE /contacts/:contactId` для видалення існуючого контакту.

Обробка цього роута має включати:

- реєстрацію роута у файлі `src/routers/contacts.js`;
- опис контролера для цього роута у файлі `src/controllers/contacts.js`;
- створення сервісу у файлі `src/services/contacts.js`.

Відповідь сервера у разі успішного видалення контакту має бути зі статусом **204** без тіла відповіді.

Якщо контакт не було знайдено, то за допомогою [**http-errors**](https://www.npmjs.com/package/http-errors) створіть помилку зі статусом **404** та повідомленням: "Contact not found".

```js
http - errors(404, 'Contact not found');
```
